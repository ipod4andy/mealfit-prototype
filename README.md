# MealFit 웹 화면 프로토타입

> 인바디로 찾는 명지대 앞 맞춤 한 끼 — DEPth 5th MVP Project, Team 건강연구소

**데모:** [GitHub Pages 링크 — 배포 후 기입]

이 레포는 제가 PM(기획 파트 리딩)으로서 **Claude Code로 만든 클릭 가능한 화면 프로토타입**입니다. 실제 서비스의 개발 구현(React, Spring Boot 등)은 팀의 개발 파트가 맡았고, 이 레포에는 포함되어 있지 않습니다.

## 이 프로토타입이 하는 것 / 하지 않는 것

| 동작함 (파일 안의 샘플 데이터 기준) | 동작하지 않음 (화면으로만 시연) |
|---|---|
| 상단 내비게이션, 화면 전환 | 인바디 OCR 자동 인식 |
| 홈 추천 필터링 (저탄수·고탄수는 1개만 선택) | AI 영양 분석·추천 계산 (값은 고정된 샘플) |
| 식당 검색, 음식 종류·세부 종류 선택 | 로그인·회원가입 인증 |
| 목표 체중 입력 시 증감량 계산 | 서버 연동, 실제 지도 |
| 인바디 점수 추이 그래프 | |

## 만든 과정

1. 처음 아이디어와 주요 기능을 정리했습니다.
2. 이를 바탕으로 Claude의 도움을 받아 요구사항 정의서 1차본을 만들었습니다.
3. 정의서를 바탕으로 Claude Code로 프로토타입을 만들었습니다.
4. 프로토타입을 직접 보면서 고칠 부분을 찾았고, Claude와 함께 **프로토타입과 요구사항 정의서를 함께 수정**했습니다.
5. [수정 횟수·AI에게 시킨 방식 — 기억나는 만큼 기입]

## 버전별 변화

`versions/`에 이전 버전을 그대로 두었습니다. 화면 내용으로 본 순서이며, 파일 이름의 번호는 수정 횟수가 아닙니다.

| | v1 (`versions/v1_first.html`) | v2 (`versions/v2_middle.html`) | v3 (`index.html`, 최신) |
|---|---|---|---|
| 내비게이션 | 좌측 사이드바 | 좌측 사이드바 | 상단 바 |
| 알레르기 입력 | 있음 | 제거 | 제거 |
| 건강 지표 | 건강 등급(A−)과 SCORE 78 링 (현재 값만) | 인바디 점수 추이 그래프 (시간에 따른 변화) | 인바디 점수 추이 그래프 (측정일 기준) |
| 목표·활동량 입력 | 없음 | 추가 | 유지, 목표 체중 증감 계산 추가 |
| 식당 카테고리 | 식당·카페·베이커리·프랜차이즈 | 한식·중식·일식·양식 + 세부 종류 | 동일, 검색·필터 동작 |
| 마이페이지 | 건강 등급, 추천 이력 | 인바디 업로드 이력 | 동일, 측정일 표시 |
| 소셜 로그인 | 있음 | 있음 | 제거 |

알레르기 입력 제외와 점수 산출 단순화(별도 산출 없이 인바디 점수 사용)는 요구사항 정의서에 남긴 결정과 같은 방향입니다.

## 정의서에 남긴 결정 (일부)

- 좌측 사이드바 → **상단바**: 소비자 서비스 톤에 맞추기 위해
- 건강 데이터 입력 강제: 빈 화면을 따로 만들지 않고 **온보딩 순서**로 해결
- 목표 선택: '증량/린매스업' 분리안을 **'근육량 증가'로 통합** (용어가 낯설고 차이가 작아서)
- 거리 필터: 임의의 기본값은 근거가 없어 **지도 화면으로 분리**
- MVP 제외: 알레르기 입력, 어드민 화면, 편의점 데이터

## 알려진 한계

- **이 프로토타입의 매칭률(MATCH %)은 계산된 값이 아닙니다.** 화면의 95%, 90% 등은 고정된 샘플 숫자이고 이 파일에는 계산식이 없습니다. 요구사항 정의서(v29) 시점에는 산정 방식이 미해결 문제였습니다.
- 이후 팀의 클래스 상세 설계서(v3)에는 다음과 같이 설계되어 있습니다. 매칭률은 영양 항목별로 `1 - |목표 - 실제| / 목표`(하한 0)를 구해 가중 합산한 뒤 100을 곱하는 **결정적(deterministic) 계산**이고, 실시간 추천 경로에는 AI 호출이 없습니다. 영양정보가 AI 추정값이면 신뢰도에 따라 점수를 감쇄합니다. 공식 산정식이 확정되지 않아 계산 클래스를 교체할 수 있는 구조로 두었습니다. 이 설계가 최종 서비스에 그대로 구현되었는지는 이 레포에서 확인할 수 없습니다.
- 저지방·저나트륨 등 필터의 기준 수치도 정의서에 예시 초안으로만 있고 확정되지 않았습니다.

## 주의

- 화면 속 식당·메뉴·인바디 수치·이메일은 모두 **샘플 데이터**입니다.
- 광고 배너는 수익 모델 검증용 화면이며 실제 광고가 아닙니다.
